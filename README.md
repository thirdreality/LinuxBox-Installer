# LinuxBox-Installer

Quick installer for HomeAssistant, zigbee2mqtt, Homekit bridge etc

## install-home-assistant-core

Official Document: [Jump to home-assistant.io](https://www.home-assistant.io/installation/linux#install-home-assistant-core)

`hacore`, `music-assistant` and `matter2mqtt` depend on `thirdreality-python3`, so
they must come from the same Python line as the `python3` deb on the device. All
other debs work with either line.
